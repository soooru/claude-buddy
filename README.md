# Claude Buddy

> **Unofficial fan-made tool, not affiliated with Anthropic.**

Claude Code 세션들을 한눈에 보는 **Windows 트레이 앱**입니다. 여러 터미널·에디터에 흩어진 Claude 세션이
지금 일하는 중인지, 나를 부르는지, 다 끝났는지를 작은 위젯 하나로 보여 주고, 사용량에 따라 자라는 픽셀 펫을 키웁니다.

## 한눈에 보기

| 기능             | 설명                                                                                |
| ---------------- | ----------------------------------------------------------------------------------- |
| **세션 현황**    | 세션마다 상태(일하는 중 · 허락 대기 · 완료)와 지금 하는 일을 보여 줍니다.           |
| **➜ 바로 가기**  | 그 세션이 도는 창·탭으로 이동합니다(Windows Terminal 탭, Cursor·VS Code 터미널 탭). |
| **🔔 알림**      | 누가 나를 부르면 제목 옆에 종이 나타납니다. 누르면 그 세션으로 갑니다.              |
| **총 사용량**    | 계정의 5시간 · 주간 한도 사용률. 한도를 넘으면 추가 과금 추정액도 표시합니다.       |
| **클마고치**     | 매주 새 알에서 태어나는 픽셀 펫. 응답마다 밥을 먹고, 주간 사용량으로 자랍니다.      |
| **🐾 미니 모드** | 위젯을 접으면 펫만 바탕화면에 떠 있습니다.                                          |
| **⚙ 설정**       | 🏠 퇴근까지 남은 시간(KST) · 📖 버디 도감                                           |

## 설치

**준비물**: Windows 10/11, Claude Code(Windows 기본 설치에 포함된 Git Bash 사용). Node.js 는 필요 없습니다.

1. **Claude Code 를 최신으로** 업데이트합니다.
   ```
   claude update
   ```
2. **설치 파일 실행** — `Claude-Buddy-Setup-x.y.z.exe` 를 실행합니다. 관리자 권한은 필요 없습니다.
   - **「Windows의 PC 보호」** 창이 뜨면 **추가 정보 → 실행**을 누르세요. 서명되지 않은 exe 라서 뜹니다.
   - 「바탕화면에 바로가기 만들기」는 원하는 대로 고르세요. 시작 메뉴에는 항상 등록됩니다.
3. **연결** — 설정 창에서 **「연결하기」** → 분홍색으로 바뀐 **「위젯 열기」** 를 누릅니다.
   위젯이 열리면서 설정 창은 닫힙니다.
4. **Claude Code 재시작** — 열려 있던 Claude Code 를 한 번 껐다 켭니다. 이제부터 기록됩니다.

이후에는 PC 를 켜면 앱이 **트레이**에 조용히 떠 있습니다.

> **트레이가 어디죠?** 작업 표시줄 오른쪽 아래, 시계 왼쪽의 **`^`** 를 누르면 숨은 아이콘들이 펼쳐집니다.
> 분홍색 픽셀 얼굴이 Claude Buddy 입니다. 작업 표시줄로 끌어 두면 항상 보입니다.

### 헤더 아이콘

| 아이콘 | 동작                                                                                    |
| ------ | --------------------------------------------------------------------------------------- |
| 🔔     | 누가 부를 때만 제목 옆에 나타납니다. 누르면 그 세션으로 이동합니다.                     |
| 📌     | 위젯을 다른 창보다 항상 위에 띄웁니다(켜기/끄기).                                       |
| 🐾     | 미니 모드(데스크톱 펫)로 전환합니다.                                                    |
| ⚙      | 설정 메뉴 — 🏠 퇴근 시간 · 📖 버디 도감                                                 |
| –      | 최소화                                                                                  |
| ✕      | **창만 닫습니다.** 앱은 트레이에서 계속 기록합니다. 완전히 끄려면 트레이 메뉴 「종료」. |

### 세션 목록

- 세션 이름 옆 **✎** 로 이름을 붙일 수 있습니다(기본값은 폴더 이름).
- **➜** 는 그 세션이 돌고 있는 창·탭으로 이동합니다. 위젯을 연 뒤 몇 초 지나야 나타납니다(세션 확인 시간).
- 끝난 세션은 1시간 뒤 목록에서 빠집니다.

| 어디서 Claude 를 쓰나요?                          | ➜ 동작                                                                                                            |
| ------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| Windows Terminal (PowerShell · cmd · Git Bash 탭) | 창 + 정확한 탭                                                                                                    |
| Cursor · VS Code 내장 터미널                      | 창 + 정확한 터미널 탭 — 연결할 때 작은 확장을 설치합니다. 설치 후 에디터에서 `Ctrl+Shift+P → Reload Window` 한 번 |
| IntelliJ 등 기타                                  | 창까지 이동                                                                                                       |

### 총 사용량

- **5시간 · 주간** 한도 사용률입니다. Pro · Max 등 **구독 로그인**일 때만 표시됩니다.
- 몇 분 전 기준인지 함께 표시됩니다. Claude Code 상태줄이 갱신될 때 함께 갱신됩니다.
- 한도를 넘으면 **「한도 초과 — 추가 과금 ($13.03)」** 처럼 표시합니다.
  이 PC 의 세션들이 한도 초과 이후 쓴 비용을 더한 **추정치**이며, 한도가 리셋되면 0 부터 다시 셉니다.

### ⚙ 설정

- **🏠 퇴근 시간** — 표시 여부와 퇴근 시각(KST)을 정합니다. 한 번 정하면 바꿀 때까지 유지됩니다.
- **📖 버디 도감** — 지금까지 태어난 버디들을 모아 봅니다.

## 클마고치 키우기

### 태어나기

- 매주 **주간 한도가 리셋될 때** 새 알이 생기고, 16종 중 한 마리가 무작위로 태어납니다.
- 알일 때는 「두근두근! 누가 태어날까?」, 깨어나면 「짠! 클마고치가 태어났어요」.
- 펫 이름을 **더블클릭**하면 이름을 지어 줄 수 있습니다.

### 자라기 — 주간 사용량 기준

| 주간 사용량 | 레벨      | 단계   |
| ----------- | --------- | ------ |
| 0 – 9%      | Lv.0      | 🥚 알  |
| 10 – 29%    | Lv.1 – 2  | 아기   |
| 30 – 59%    | Lv.3 – 5  | 어린이 |
| 60% 이상    | Lv.6 – 10 | 어른   |

- 레벨 = 주간 사용률 ÷ 10. 주간 한도가 리셋되면 다시 알부터 시작합니다.
- 사용량 정보가 없는 계정(API 키 등)은 **주간 출력 토큰**(100만 토큰 = 100%)으로 대신 셉니다.

### 밥

- Claude 의 **응답이 끝날 때마다 한 칸**(최대 5칸) 찹니다.
- **30분에 한 칸씩** 소화합니다. 밥이 0 이면 배고파해요.

## 미니 모드 (데스크톱 펫)

위젯의 🐾 또는 트레이 메뉴 「미니 모드」로 켭니다.

- 펫만 바탕화면에 떠 있습니다. **드래그**로 옮기고, 화면 가장자리까지 갈 수 있습니다.
- **클릭**: 쓰다듬기 · **더블클릭**: 그 자리에서 위젯으로 펼치기(위젯 → 펫도 그 자리에서).
- 누가 부르면 **말풍선**이 뜹니다. 말풍선을 누르면 그 세션으로 이동합니다.

트레이 아이콘을 **클릭**하면 위젯(또는 펫)을 열고 닫습니다. **우클릭** 메뉴:

| 메뉴                    | 설명                           |
| ----------------------- | ------------------------------ |
| 열기 / 닫기             | 위젯(또는 펫) 열고 닫기        |

| Claude Code 연결 설정…  | 연결 · 다시 연결 · 연결 해제   |
| Windows 시작 시 실행    | 로그인할 때 트레이로 자동 실행 |
| 정보                    | 버전 확인                      |
| 종료                    | 앱을 완전히 끕니다             |

## 업데이트 · 제거

### 업데이트

- 새 설치 파일을 **그대로 실행**하면 됩니다. 연결 상태와 펫 · 도감 · 기록은 이어집니다.
- 트레이에서 「종료」한 뒤 설치하면 깔끔합니다.

### 제거

- 트레이 우클릭 → **Claude Code 연결 설정… → 연결 해제**: 앱은 두고 Claude Code 연결만 끊습니다.
- **Windows 설정 → 앱 → Claude Buddy 제거**: 연결 해제 후 앱을 지웁니다. 데이터도 지울지 묻습니다.

어느 쪽이든 `settings.json` 에서 **Claude Buddy 가 넣은 항목만** 빠지고, 원래 쓰던 상태줄이 복원됩니다.

## 자주 묻는 질문 · 문제 해결

<details>
<summary><b>앱을 끄거나 PC 를 끄면 어떻게 되나요?</b></summary>

- Claude Code 는 앱과 상관없이 **정상 동작**합니다.
- 그동안의 이벤트는 파일로 쌓여 있다가, 앱이 다시 켜지면 순서대로 반영됩니다(밥도 소급). 7일 넘은 것은 버립니다.
- 강제 종료된 세션은 잠깐 「작업 중」으로 남을 수 있습니다. 앱이 켜지고 2분쯤 뒤 살아 있는 세션을 다시 확인하면서 정리됩니다.
</details>

<details>
<summary><b>위젯에 세션이 안 떠요</b></summary>

1. 연결 후 **Claude Code 를 재시작**했는지 확인하세요. 이미 열려 있던 세션은 새 설정을 읽지 않습니다.
2. 트레이 우클릭 → Claude Code 연결 설정… 에서 연결 상태를 확인하고, 필요하면 「다시 연결」.
3. Git Bash 가 없으면 훅이 돌지 않습니다. Claude Code 를 Windows 기본 설치로 쓰고 있는지, `claude update` 했는지 확인하세요.
</details>

<details>
<summary><b>총 사용량이 안 보여요</b></summary>

- 구독(Pro · Max 등) 로그인일 때만 나옵니다.
- Claude Code 가 상태줄을 한 번 그린 뒤부터 나옵니다. 아무 메시지나 한 번 보내 보세요.
</details>

<details>
<summary><b>원래 쓰던 상태줄이 사라졌어요</b></summary>

사라지지 않습니다. Claude Buddy 는 사용량만 저장하고 **원래 상태줄을 그대로 실행**합니다.
이상하면 트레이 → 연결 설정 → 「다시 연결」, 그래도 안 되면 「연결 해제」로 원래대로 돌릴 수 있습니다.

</details>

<details>
<summary><b>➜ 가 엉뚱한 곳으로 가거나 안 보여요</b></summary>

- 위젯을 연 뒤 몇 초 기다리세요(세션 확인 중에는 숨겨져 있습니다).
- Cursor · VS Code 는 확장이 필요합니다. 트레이 → 연결 설정 → 「다시 연결」 후 에디터에서 `Reload Window`.
</details>

<details>
<summary><b>바탕화면 바로가기 아이콘이 깨져 보여요</b></summary>

업데이트로 exe 가 바뀌었는데 Windows 아이콘 캐시가 예전 것을 기억하는 경우입니다.
바탕화면에서 **F5**, 안 되면 로그아웃 후 다시 로그인하세요. 그래도 안 되면 바로가기를 지우고
시작 메뉴의 Claude Buddy 를 바탕화면으로 끌어다 놓으면 됩니다.

</details>

<details>
<summary><b>보안 프로그램이 설치를 막아요</b></summary>

서명되지 않은 시험판이라 막힐 수 있습니다. 「추가 정보 → 실행」으로 진행하고, 회사 보안 정책으로 막히면 담당자에게 문의하세요.

</details>

## 무엇을 바꾸나요?

「연결하기」는 `~/.claude/settings.json` 을 **백업한 뒤** 아래 항목만 추가합니다. 다른 설정은 건드리지 않습니다.

- **훅 7개** — 백그라운드(`async`) 명령. 이벤트를 `~/.claude/session-dash/inbox/` 에 작은 파일로 남기면 앱이 읽고 지웁니다.
  네트워크를 쓰지 않고, Claude Code 의 동작에 끼어들지 않습니다.
- **상태줄** — 이미 쓰는 상태줄이 있으면 **그 상태줄이 그대로** 보이고, 앞에서 사용량만 저장합니다. 없으면 간단한 상태줄을 보여 줍니다.
- (선택) **Cursor · VS Code 확장** 「Claude Buddy Terminal Focus」 — ➜ 가 에디터 안의 정확한 터미널 탭을 찾게 합니다.

백업은 `settings.json.bak-claude-buddy-날짜` 로 남습니다(연결 전 원본과 최근 4개).

## 데이터

| 무엇                           | 어디                                        |
| ------------------------------ | ------------------------------------------- |
| 세션 기록 · 펫 · 사용량 · 설정 | `~/.claude/session-dash/` (이 PC 에만 저장) |
| 위젯 창 위치                   | `%APPDATA%\Claude Buddy\`                   |

- Claude Buddy 는 **외부 서버로 아무것도 보내지 않습니다.**
- 세션 기록은 30일이 지나면 자동으로 지웁니다.

## 보안

자세한 내용은 [SECURITY.md](SECURITY.md). 요약:

- 훅은 포트 대신 **내 사용자 폴더의 파일**로 전달됩니다. 다른 프로그램이 가로채거나 Claude Code 에 응답을 꾸며 보낼 수 없습니다.
- 위젯용 로컬 서버는 `127.0.0.1` 에만 열고, **실행마다 새로 만드는 키**가 있어야 기록을 내줍니다.
- 화면은 CSP · 샌드박스 · contextIsolation 안에서 돌고, 다른 페이지로 이동하거나 새 창을 열지 못합니다.

## 개발

```bash
npm install
npm start               # 개발 실행
npm run security-test   # 보안 시험
npm run check           # 공개 전 개인정보·비밀 점검
npm run dist            # 설치 파일(dist/)
```
