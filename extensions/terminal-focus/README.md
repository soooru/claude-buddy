# Claude Buddy Terminal Focus

Companion extension for [Claude Buddy](https://github.com/soooru/claude-buddy) (Cursor / VS Code).
When you press ➜ on a session in the Claude Buddy widget, this extension shows the terminal tab
that runs that Claude Code session. It only reads/writes small files in `~/.claude/session-dash`
and never uses the network.

Unofficial fan-made tool, not affiliated with Anthropic.
